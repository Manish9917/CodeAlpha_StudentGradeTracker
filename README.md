
# CodeAlpha Student Grade Tracker

## About the Project
A console-based Java application developed for the
CodeAlpha Java Programming Internship Task 1.

The application accepts student names and marks,
calculates grades, and generates a summary report.

## Features
- Input multiple student names and marks
- Validate marks between 0 and 100
- Calculate individual student grades
- Calculate total and average marks
- Find highest and lowest marks
- Display a formatted student report

## Technologies Used
- Java
- Scanner
- Arrays
- Loops and conditional statements
- Methods

## How to Run

1. Install the Java JDK.
2. Open the project folder in a terminal.
3. Compile the program:

   javac StudentGradeTracker.java

4. Run the program:

   java StudentGradeTracker
