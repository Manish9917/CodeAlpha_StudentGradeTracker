
# CodeAlpha Student Grade Tracker

A Java console application developed for CodeAlpha
Java Programming Internship - Task 1.

## Features
- Manage multiple students
- Store marks for Java, C Programming, and DBMS
- Validate marks between 0 and 100
- Calculate each student's total and average
- Assign grades based on average marks
- Find the highest and lowest subject scores
- Display individual student reports
- Display an overall class summary

## Technologies
- Java
- Scanner
- One-dimensional and two-dimensional arrays
- Loops and conditional statements
- Methods

## How to Run
Compile:
javac StudentGradeTracker.java

Run:
java StudentGradeTracker

## Grade Rules
- 90 and above: A+
- 80 to 89.99: A
- 70 to 79.99: B
- 60 to 69.99: C
- 40 to 59.99: D
- Below 40: F
